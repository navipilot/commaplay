    浏览器音量

    画面连接后会自动尝试将声音交给浏览器播放。若浏览器限制有声自动播放，点按画面或「启用声音」即可授权；音量仅保存在当前浏览器。Siri 与电话麦克风仍受 HTTP 限制。

    特斯拉热点连接

    正在检查热点…

    打开特斯拉入口：99.99.99.99:8080

    驻车后在 comma3 网络设置中开启热点，将特斯拉车机连接到该热点，然后在车机浏览器输入 http://99.99.99.99:8080。热点状态与地址映射自动更新，无需手动添加规则。

    该入口仅对连接 comma3 热点的客户端有效。iPhone 的 CarPlay 网络配置也需与热点一致；热点开启不代表有互联网，切换热点可能断开当前 Wi-Fi、SSH 和 CarPlay。
